# Aplicativo de Reajuste Salarial

Este é um aplicativo Android simples criado com Android Studio, que permite calcular o **novo salário** de um funcionário com base em **três percentuais de aumento predefinidos** (40%, 45% ou 50%).

---

## Tecnologias Utilizadas

- Java (Android)
- XML (Layout)
- Android Studio
- API mínima: 21 (Lollipop)

---


## 🎨 Layout e Estilo

- Layout construído com `LinearLayout` vertical
- Estilo clean com tons claros (`#FAFAFA`)
- Botão centralizado com **Azul* (`#0000FFv`)
- Texto em branco para contraste visual


---

## 🧪 Funcionamento

1. O usuário digita o valor do salário atual.
2. Seleciona uma das opções de reajuste:
   - Reajuste de 40%
   - Reajuste de 45%
   - Reajuste de 50%
3. Clica no botão **“Atualizar Pagamento”**
4. O app exibe o novo salário calculado na parte inferior da tela.
